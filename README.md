# Личен контролен център — тестово PWA

Малко българско PWA приложение за лично ползване. То демонстрира тъмен responsive интерфейс, интерактивни превключватели, плъзгач, локално запазване на настройките, manifest и service worker за офлайн работа.

## 1. Тестване локално на компютър

1. Разархивирай папката и отвори PowerShell в нея.
2. Стартирай локален HTTP сървър:

   ```powershell
   py -m http.server 4173 --bind 127.0.0.1
   ```

3. Отвори `http://127.0.0.1:4173/` в Chrome или Edge.
4. Промени превключвателите и плъзгача. Настройките се пазят в `localStorage`.
5. В Chrome отвори DevTools → Application → Service Workers и провери, че `sw.js` е активен.
6. В DevTools → Network избери Offline и презареди страницата. Панелът трябва да остане достъпен от кеша. Върни избора на No throttling след теста.

> Важно: `file:///.../index.html` не е достатъчно за PWA тест — service worker работи през `localhost` или HTTPS.

## 2. Публикуване с GitHub Pages

1. Създай GitHub repository, например `personal-control-center`.
2. Качи съдържанието на тази папка в корена на repository-то. `index.html` трябва да е в корена.
3. В GitHub отвори **Settings → Pages**.
4. Под **Build and deployment** избери **Deploy from a branch**, branch `main`, folder `/ (root)` и натисни **Save**.
5. Изчакай публикуването и отвори адреса, който GitHub Pages показва. GitHub Pages използва HTTPS, което е необходимо за service worker и инсталация.

## 3. Инсталиране през Chrome на Android

1. Отвори HTTPS адреса на GitHub Pages в Chrome на телефона.
2. Изчакай страницата да се зареди веднъж онлайн.
3. Отвори менюто `⋮` → **Добавяне към началния екран** или **Инсталиране на приложението**.
4. Потвърди името и натисни **Инсталиране**.
5. Стартирай иконата от началния екран. Приложението се отваря в самостоятелен прозорец заради `display: standalone`.

## Структура

- `index.html` — интерфейс, стилове и интеракции.
- `manifest.webmanifest` — име, икони, цвят и режим на стартиране.
- `sw.js` — кеширане и offline fallback.
- `icons/` — SVG икони 192×192 и 512×512.

Приложението не изпраща данни към външен сървър. Настройките се съхраняват само в браузъра на конкретното устройство.
